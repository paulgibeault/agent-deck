          Welcome to agent-deck

          A cockpit for every Claude Code session on this machine. It needs its local backend to see them.

          Backend isn't running

          Launch backend

          Nothing happening? The launch button needs a one-time helper install. In the agent-deck folder run npm run install-app, then try again.

          Start it yourself

          From the agent-deck folder:

          npm start

          This window reconnects on its own as soon as the backend answers.

          New session

          Runs claude under the deck, so you can send, queue, interrupt and answer permission prompts from here.
